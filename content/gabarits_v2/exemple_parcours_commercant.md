# Exemple de parcours prévu : un maquis montre la préparation d’un plat

**Exemple de fonctionnement, pas une application déjà construite ou testée.** Le plan « Avant et après » pour un restaurant ou un maquis prévoit quatre prises.

## 1. Choisissez la vidéo et remplissez les informations

Vous choisissez **Avant et après**. Pour ce format, le plan vidéo prévoit de montrer les ingrédients, la cuisson, le dressage et le plat terminé.

Vous saisissez le nom du maquis, le numéro WhatsApp, le nom du plat, le prix et le lieu. FCFA est sélectionné par défaut. Vérifiez que les informations sont exactes. Rien n’est gardé dans un profil pour la prochaine vidéo.

## 2. Filmez les quatre prises prévues

Chaque prise dure environ 12 secondes. Tenez le téléphone debout, près d’une fenêtre, et évitez de mettre la lumière derrière le plat.

1. **Les ingrédients** : posez les ingrédients sur une table propre et filmez-les d’en haut.
2. **La cuisson** : filmez une vraie action de cuisson ou de grillade.
3. **Le dressage** : filmez vos mains pendant que vous mettez le plat dans l’assiette.
4. **Le plat terminé** : filmez le plat de près. Si de la vapeur sort vraiment, vous pouvez la montrer; n’en ajoutez pas.

Ce sont les quatre prises prévues. Vous ne filmez pas une prise supplémentaire pour parler et vous n’avez pas à couper les images vous-même.

## 3. Exemple de consigne orale

Dans la scène parlée qui montre les ingrédients, le guide prévu pourrait afficher :

- **À montrer :** les ingrédients du plat.
- **À raconter :** ce que vous avez choisi pour le préparer.
- **Exemple pour comprendre, pas à répéter :** « Voici les ingrédients. »
- **Temps conseillé :** environ 2 secondes. C’est un repère, pas une coupure automatique; vous pouvez finir votre idée pendant l’image suivante.

Vous parlez avec vos propres mots, en français ou dans la langue que vous voulez. Le bouton **Suivant** marquera la fin de l’extrait de voix dans la prise déjà demandée. Les autres scènes restent muettes si le plan vidéo les prévoit ainsi; vous pouvez aussi choisir une vidéo sans parole. La voix reste à vitesse normale, même si l’image de cuisson est accélérée.

## 4. Ce que le plan vidéo prévoit

La vidéo finale est prévue pour durer environ **35 secondes**. Une prise peut servir à plusieurs scènes :

| Moment | Ce que le plan vidéo prévoit de montrer |
|---|---|
| Au début | Le plat terminé et un titre qui annonce le passage des ingrédients au plat prêt. |
| Ensuite | Les ingrédients et les épices, montrés de près. |
| Puis | La cuisson et le grill, parfois accélérés. |
| Après | Les mains qui dressent le plat. |
| Le résultat | Le plat fini, montré de près. |
| Avant la fin | Le prix saisi dans le formulaire. |
| À la fin | Le nom du maquis, le lieu et le numéro WhatsApp. |

Le plat peut apparaître au début même si vous l’avez filmé en dernier. L’ordre des images est prévu dans le plan vidéo; vous n’assemblez pas les images vous-même.

## 5. Musique et sons

Le plan vidéo propose une direction musicale douce pour ne pas couvrir la voix. Un son de cuisson peut être prévu. Ce sont des idées de recherche : aucun fichier de musique ou de son n’est déjà fourni comme acquis ou autorisé. Les droits devront être vérifiés avant de les utiliser dans une vidéo commerciale.

**À retenir :** les prises et le scénario sont décrits dans les fichiers. L’écran de tournage, la préparation automatique de la vidéo et la sélection de musique ne sont pas encore construits ni testés.
