# D42.21 — 02. FICHES DE DIRECTION MUSICALE DES 30 GABARITS

Construites à partir des TIMELINES RÉELLES (donnees/timelines_30_gabarits.json, extraits des
JSON gabarits V2.0 scène par scène), de la matrice audio D42.19 (BPM/genre/énergie/riser/drop/
SFX — sources : JSON gabarits), des mesures objectives v2 (600/600 pistes mesurées) et de la
recherche documentaire (cp. D42.20-03 : TikTok/Meta/Oakes 2007/Oakes & North 2006/Galan 2009/
EBU R128 s1-s2/AES TD1004/ITU-R BS.1770-4).

Principes transverses (chacun justifié par une source identifiée dans le cp. D42.20-03) :
- hook sonore immédiat (≤ 0,3 s) — TikTok : l'accroche se joue dans les 3 premières secondes ;
  défaut v2 mesuré : silence numérique 0–0,5 s + première attaque > 2 s sur 100 % de l'échantillon ;
- congruence musique-message par secteur ET par gabarit (Oakes 2007 ; Galan 2009) — jamais une
  seule identité pour les 6 secteurs ;
- tempo justifié par la cadence de montage (temps/coupe), pas copié d'un autre gabarit ;
- énergie ≠ volume : la dynamique vient de l'arrangement (Oakes & North 2006 : tempo ET timbre) ;
- 20 variations réellement exploitables par gabarit (renouvellement créatif TikTok/Meta) ;
- voix toujours facultative : la musique fonctionne seule (scénario A) et se retire sous la
  voix (scénario B, ducking gabarit) ;
- aucune de ces règles n'est une promesse de conversion : validation à l'écoute puis en tests terrain.
